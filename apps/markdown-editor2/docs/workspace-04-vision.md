**発想の発散は Phase 1（Lv2-4）で一度きり。以降の Phase では追記のみとし、発散の場を持ち越さない。**（Charter §8 準拠）

Phase 2 以降の実施中に新しいアイデアが出た場合は、本文書へ追記して「本 Refine 対象外」と明示する。実装スコープへの取り込み判断は行わない（スコープ膨張を防ぐため）。

## 北極星——3 つの到達像

個別構想の羅列に先立ち、MEW（Markdown Editor Workspace）がどのような文書リーダーになり得るかを物語として示す。

1. **「ローカルの読書室」**（第 1 層の完成形）：ブラウザを開けば自分の文書群が
   本棚のように並び、続きから読め、読了が積み上がる。インストールも
   アカウントもインデックス待ちもない、最速で「読む」に到達できる場所

2. **「文書群の交差点」**（第 2 層の完成形）：人が読み、AI が要約し、リンク網が
   知識をつなぐ。ローカルのフォルダが、人間と AI が同じ文書を読み書きする
   時代の「共有読書台」になる

3. **「Markdown の出版社」**（第 3 層・PJ 転換後の姿）：読む道具で完成した
   組版品質をそのまま、1 冊の本にも、配布サイトにも綴じ直せる。
   「書く→読む→配る」がローカルで完結する

## 第 3 層：性格の転換（別 PJ 級の構想）
