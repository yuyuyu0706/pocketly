reST Editor **yellow**
======================

このエディタはブラウザだけで reStructuredText を HTML に変換してプレビューするドラフト版です。

使い方
------
- 左ペインに reST を入力する。
- 右ペインに即時プレビューが表示される。
- ツールバーから **保存**, **HTML**, **PDF** を実行する。

数式: $\int_0^1 x^2 \, dx = 1/3$

コードブロック::

  def greet(name):
      print(f"こんにちは、{name}")

リンク: https://docutils.sourceforge.io/docs/user/rst/quickstart.html
